How to Install SY Chat

Your browser hasn't triggered the automatic install popup yet. Follow the quick steps below for your device:

iPhone / iPad (Safari)
  1. Tap the Share icon (⎋) at the bottom of Safari.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add in the top-right corner.
Chrome / Edge / Android
  1. Click the Install App icon in the browser address bar (or open the ⋮ menu).
  2. Select Install SY Chat or Add to Home screen.
